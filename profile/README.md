# MOS Studio

EffectCraft 的 MOS 效果，四个插件合并成一套，安装器与效果栏都支持中文 / English。

| 效果 | id | 分组 | 版本 |
| --- | --- | --- | --- |
| [mos_阴影 / mos_shadow](https://github.com/mossls-studio/mos-shadow) | `mos.shadow` | MOS 视效 / MOS VFX | 0.6.2 |
| [mos_抖动 / mos_shake](https://github.com/mossls-studio/mos-shake) | `mos.shake` | MOS 形变 / MOS Deform | 1.2.0 |
| [mos_收缩 / mos_shrink](https://github.com/mossls-studio/mos-shrink) | `mos.shrink` | MOS 形变 / MOS Deform | 1.3.7 |
| [mos_灯光混合 / mos_lightmix](https://github.com/mossls-studio/mos-lightmix) | `mos.lightwrap` | MOS 视效 / MOS VFX | 1.4.0 |

安装：[MOS Suite 1.0.0](https://github.com/mossls-studio/mos-suite/releases/tag/v1.0.0)（Material 3 安装器，中英可选，默认跟随系统）。套件源码与手动安装说明在 [mos-suite](https://github.com/mossls-studio/mos-suite)。

Four MOS effects for EffectCraft, shipped as one suite with a bilingual installer and bilingual Effects panel.
